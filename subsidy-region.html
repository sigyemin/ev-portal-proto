      잔여 대수 안내

      잔여 대수는 목표 대수 기준 단순 계산값으로, 차종별 지급액에 따라 실제 지원 가능 대수와 차이가 발생할 수 있습니다.

      예산현황 (선정 기준)참고용 현황

      카테고리별 분포

      개발 안내 접수기간 상태 처리 규칙 — 실제 화면에는 노출하지 않습니다

      1. 접수기간 판정

      • 기준 : 현재시각 이 해당 지자체의 공고 차수별 접수기간(시작일시 ~ 종료일시) 안에 있는지
      • 여러 차수(본공고 · 추경1차 · 추경2차 …) 중 현재시각이 포함되는 차수가 하나라도 있으면 접수기간 중
      • 포함되는 차수가 없으면 접수기간 아님 (마감된 경우 · 아직 시작 전인 경우 모두)
      • 시각이 등록되지 않은 차수는 시작 00:00 · 종료 23:59 로 간주

      2. 접수기간 아닐 때

      • 신청마감 줄(공고 차수 · 공고문 아래)에 마감 빨간 뱃지 + 마감일시를 빨강으로 표시 (접수 중이면 접수중 뱃지)
      • 선정잔여 · 출고잔여 대수와 예산현황 막대, ① 카드를 회색(비활성)으로 표시. 수치는 지우거나 0으로 바꾸지 않고 그대로 둔다
      • 제목 옆에 참고용 현황 꼬리표 표시

      3. 접수기간 중일 때

      • 안내문 · 회색 처리 · 꼬리표 모두 없이 현행 그대로 표시

      4. 참고

      • 잔여 대수를 숨기지 않는 이유 : 추경 등 추가 공고로 접수가 재개될 수 있고, 다음 차수를 준비하는 이용자에게 필요한 정보이기 때문
      • 기존 문제 : 접수는 마감되었는데 잔여 대수만 보여 지금 신청 가능한 것으로 오해 → 판정에 접수기간 축이 없었던 것이 원인
      • 프로토 기준일 : 스크립트 상단 TODAY · NOW_TM 상수. 값을 바꾸면 접수 중 / 접수기간 아님 두 상태를 모두 재현할 수 있다

      5. [ISS-135] 변경 이력

      • ① 지금 신청 카드 상태를 2단계로 축소 : 운영 psLocalList.jsp 는 3단계(마감 / 임박(warning) / 신청 가능)이나, 프로토는 사용자 확정으로 2단계(마감 / 신청 가능) — 중간 임박 단계 제거
      • 상단 안내박스(#detailPeriodOff) 제거 : 운영에 없는 요소이고, 신청마감 줄의 마감 뱃지가 같은 정보(접수기간 종료)를 전달해 중복 → 제거. 단 is-period-off 회색 처리(카드 · 그래프)와 참고용 현황 꼬리표는 유지
      • 접수중 뱃지 문구는 미정(개발 협의) : 운영 소스에 신청마감의 접수상태 뱃지 대응 표기가 없어 프로토 임의값(접수중 · badge--success)으로 표시
