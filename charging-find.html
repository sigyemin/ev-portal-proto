            개발 안내 통합지도(전기차) 개선 — 프로토타입 전용 · 실제 화면 비노출

            1. 필터 다중선택 (시/도 · 시/군·구 · 충전소분류 · 충전기타입 · 충전방식)

            • 5개 필터 모두 목록 맨 위에 전체 항목 + 개별 항목. 값이 비면([]) 전체로 간주.
            • 규칙: 전체 체크 → 나머지 해제 / 개별 체크 → 전체 해제 / 아무것도 없으면 전체.
            • 버튼 라벨 요약: 전체 / 서울특별시(1개) / 서울특별시 외 2(2개+).
            • 구현: 기존 dropdown 껍데기 + 기존 checkbox 조립(퍼블 신규 컴포넌트 없음, 칩 미사용). 열림·외부클릭 닫기는 ui-common.js(.checkbox 클릭은 닫힘 예외), Esc 닫기는 페이지 스코프.
            • 시/도↔시/군·구 연동: 선택된 시/도의 zcode 앞 2자리에 해당하는 gugun 합집합으로 시/군·구 항목을 재구성. 시/도=전체면 시/군·구는 '전체'만(74개 전개는 과함). 시/도 변경 시 시/군·구는 전체로 리셋.

            2. 초기 진입 시 카드리스트 미노출

            • 진입 직후 리스트를 그리지 않고 안내문구 지역을 선택하고 검색해 주세요. 만 노출, 총건수 0.
            • 검색 버튼 · 검색어 Enter · 즐겨찾기 · 마이페이지 bookmark 진입 시 listActivated=true 로 전환 후 리스트 렌더.
            • 마커는 진입부터 표시(선택). 사유: evMapCore 의 클러스터/마커 렌더는 사이드 리스트 구독과 독립이라 리스트만 지연해도 성립하고, 지도가 지역 감을 먼저 제공.

            3. 초기 지도 척도

            • 변경 전: center [127.5, 36.3], zoom 7.
            • 변경 후: center [127.5, 36.3], zoom 7 — 운영(ev.or.kr)과 동일한 값. 남한 본토가 화면에 꽉 차게 잡히는 척도이며, 운영 evMapCore.js 초기값과 일치한다. (검토 과정에서 [127.7, 36.0] / 6.9 로 축소했다가 운영 화면 대비 너무 멀어져 원복함)
            • ★ evMapCore.js 는 수소(charging-find-h2.html)와 공유 — 분기 없이 공유 수정. 두 지도 모두 남한 본토 노출 확인.

            4. 카드리스트 더보기

            • 초기 10건, 더보기 클릭당 +10(재정렬·재요청 없이 다음 구간 append).
            • 변경 전: RENDER_LIMIT=500 일괄 렌더 + 이하 생략... 1줄 — 500 초과분은 볼 수 없었음.
            • 정렬 무변경: 워커가 정렬한 lastStations(기후부 우선 → STAT_ID 순)를 slice 만. 거리순 미채택(정렬은 워커 소유, 현 정렬 유지가 요구).
            • 페이지네이션 대신 더보기 채택 사유: 지도-리스트가 한 화면에 묶여 페이지 이동 시 마커 동기화가 모호 / 모바일 페이저가 지도를 잠식 / 무한스크롤보다 접근성↑(aria-live) / 데이터·통계 화면(data.html)과 일관.
            • 재검색·필터 변경 시 render 재호출로 초기 10건 리셋. 더보기 버튼은 button--secondary + arrow-down(data.html chart-more 패턴).
            • ★ evMapList.js 는 수소와 공유 — 수소 페이지도 10+더보기 동일 적용(개선).

            5. 충전기 타입 필터 (ISS-146)

            • 충전기 타입 필터: 코드표 원천 = 운영 evMapEvView.js:10~12 실측 11종(01 DC차데모 · 02 AC완속 · 03 DC차데모+AC3상 · 04 DC콤보 · 05 DC차데모+DC콤보 · 06 DC차데모+AC3상+DC콤보 · 07 AC3상 · 08 DC콤보(완속) · 09 NACS · 10 DC콤보+NACS · 11 DC콤보2(버스전용)). CHARGER_TYPE 로 정의, 노출 순서 01→11 + '전체'.
            • 연결: buildEvMapFilters.chgerType = MS.ctype.getValues()(배열, 전체면 []) → 워커 passesFilters 가 충전소 하위 chargers[cid].ctp 를 include 판정(선택 타입 충전기를 하나라도 보유한 충전소만 목록·마커 통과). setStat 의 filterType(제외 semantics)과는 별개.
            • 완속/급속 구분은 02·08 = 완속(evMapMarker.js:37), 나머지 9종 = 급속. 더미(data/chlist.json)도 이 규칙에 맞춰 완속 충전기(po<30)엔 02·08만, 급속(po≥30)엔 나머지 9종만 배분.

            5-1. 미정 · 개발 협의 필요

            • 시/군·구 '전체' 처리: 시/도=전체일 때 74개 개별 전개 대신 '전체'만. 미정(개발 협의).
            • 워커 배열 하위호환: evMapWorker2.js passesFilters 의 zcode/zscode/statType 을 스칼라·배열 모두 처리. 이 워커는 전기 전용(수소는 evMapH2Worker.js 별개)이라 수소 무영향.

            6. 더미데이터 보강 (ISS-131 · data/chlist.json)

            • 충전소 272개 / 충전기 765대, 전국 17개 시/도 각 16개 균등 분포(수도권 편중 제거). zs=#pageInfo gugunList 실제 5자리 시군구 코드로 교체(기존 2자리 → 시/군·구 필터 정상화).
            • ★ x=위도(33.4~37.97) · y=경도(126.4~129.3) 준수(워커 파싱 규약 — 반대로 넣으면 '내 주변' 0건 사고).
            • 충전소 1곳에 충전기 1~5대(같은 sid, 여러 cid) 케이스 포함.
            • 대표상태(마커) 5종 모두 생성: 사용가능105·사용중81·사용불가32·이용자제한27·상태미확인27(normalizeStat 기준). cst 분포 2/3/1·4·5/0·8·9 + lm='Y'(이용자제한).
            • 출력 밴드(마커) 5종 모두 생성: 완속/중속/급속/급속+/초급속 각 ~54개. 출력 밴드는 po 가 결정(setMode)하며 ctp 와 독립 — ISS-146 에서 ctp 를 11종으로 재분포해도 po 불변이라 밴드·마커·뱃지 무변경.
            • fem/fen 환경부 5밴드 294.3~391.9원 범위 내(비회원≥회원). cm: 40% 기후부 직영('00') — 상태강제 코드(17/18/27/60/125) 제외.
            • 판단: st(skindt)는 핸드오프상 보통 ''이나, 이미 노출된 충전소 분류 필터를 실동작시키려 evMapEvView.js STATION_TYPE 코드표(A0~J0)를 라운드로빈 배정. 근거 있는 코드값으로 필터 데모 가능 — 협의 시 원복 가능.

            7. stat.json 처리 (실시간 오버레이 미사용)

            • data/stat.json = {"statList":[]} 빈 채로 유지. 워커 loadStats 는 chargerList형(sid,cid,cst,tst) 실시간 오버레이를 기대 — 비어 있으면 chlist.json 의 cst 가 마커 상태를 그대로 결정.
            • 오버레이로 덮으면 위에서 설계한 상태 5종 분포가 깨지므로 빈 유지가 맞다(콘솔 에러 없음 확인).

            8. 즐겨찾기 정상화 (프로토 = localStorage)

            • 운영은 로그인 회원 서버 저장(PS_LOCAL_BOOKMARK) — 프로토는 localStorage 키 proto.chargeBookmark(['MD000001',...] 배열). subsidy-region.html 의 proto.localBookmark 패턴과 동일 방식.
            • 구현 위치: 페이지 하단 MOCK ajax 인터셉터(MOCK_BOOKLIST=목록 조회 → localStorage, MOCK_BOOKMARK=write/delete → localStorage 저장 후 resultCd:'200'). evMapList.js·공유 JS 무수정 → 수소 무영향.
            • 로그인 게이트 우회: PAGE_INFO.loginYn='Y'(프로토 전용)로 별표 토글·즐겨찾기만 보기 활성화. jQuery 동기 로드라 $(function) 이전에 ajax 패치 → 초기 조회 레이스 없음.
            • 동작: 항목 별표 토글 · 상단 즐겨찾기만 보기 필터(워커 bookmarkMap) · 재검색·재진입 후 유지.

            9. 엑셀 다운로드 · 범례

            • 엑셀: 운영 form_excel→/monitor/evMapExcel.do 미연동 → 현재 검색결과(lastListStations, 워커 filterResults 전건)를 클라이언트 CSV(BOM+UTF-8)로 생성·다운로드(downloadListCsv()). 컬럼: 충전소명·운영기관·시도·시군구·충전기수·대표상태·최저요금·이용시간·이용제한. 결과 없으면 인라인 안내(alert 미사용).
            • 범례: 지도 하단 2행(상태5·출력5). 마크업만 추가, 스타일은 style.css 의 .map-container .map-legend(기존 보유, 무변경) 사용. 색상은 evMapMarker.js STAT_COLOR/BAND_COLOR 와 정확히 일치(인라인 --color). 운영 퍼블 마크업의 완속 #1ba877 는 마커색과 불일치 → BAND_COLOR.slow #7ACA93 로 교정.

            10. 위치사진 (ISS-148 · AS-IS 이식)

            • 원천: 위치사진 = ATCH 테이블 첨부 — 운영 조회 URL /file/viewImage.do?atch_id={ATCH_ID}(evMapInfo.jsp:237~249 · evMap.js:160~185). 상세 패널 최하단에 섹션 「위치사진」 노출, 이미지 alt="충전소 사진", 없으면 「이미지 준비중」(문구 원문 유지).
            • 프로토: /file/viewImage.do 미동작 → 플레이스홀더(회색 더미 인라인 SVG, "예시 이미지" 텍스트)로 대체(__MOCK_DETAIL 의 mockImgList · phImg). 가짜 실사진 금지.
            • 배분(결정성): 다수 충전소는 imgList=[](→「이미지 준비중」). sid 끝자리 '3'→3장 · '7'→2장만 플레이스홀더(운영도 사진 없는 곳이 흔함). 렌더는 EV 전용 어댑터 evMapEvView.js photosHtml()(썸네일 .station-photos__item), 수소(evMapH2View.js)와 별개 어댑터라 H2 무영향.
            • 클릭 확대: 썸네일 클릭 → 경량 오버레이(dim+중앙 이미지). 폭 = min(500, max(200, naturalWidth)) — AS-IS detailImage() 상한 500 · 하한 200px 준수. 더미 폭을 150/320/600/240/480 로 다양화해 클램프 확인 가능. 스타일은 map-list.css(style.css 무변경).
