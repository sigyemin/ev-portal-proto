① 상담 유형 탭 & 대화 이력

  • [ISS-149] 상단 상담 유형 = 무공해차 백과(info-evcar)와 동일한 밑줄형 tab--nav(PC) + 셀렉트 tab--mobile(모바일). 선택 상태 tab__item--selected. ★백과는 location.href로 페이지 이동하지만 헬프데스크는 같은 화면에서 대화 영역만 전환(껍데기만 이식, 전환 로직은 기존 chatType/selectTab 유지). PC 밑줄탭↔모바일 셀렉트 선택 상태 동기화.
  • [ISS-142] 딥링크 유지 : 메가메뉴 소통·지원 > AI 헬프데스크 > 충전 도우미(?tab=charge) / 보조금 도우미(?tab=subsidy) 진입이 각 탭으로 열린다. 값이 없거나 오타면 기본(충전 도우미). 탭 전환 시 history.replaceState로 주소도 갱신(?tab=charge|subsidy).
  • 대화 이력 목록 UI는 두지 않는다. 운영상 이력은 스레드ID 유지 · 동시 정원 40명 · 유휴 30초 시 스레드 해제로, 항구 저장이 아니다. 따라서 좌측 이력 사이드바(목록·접기/펼치기·드로어)를 제거하고 현재 스레드만 표시한다. ‘새로운 대화’는 현재 스레드를 초기화(비움 + 첫 진입 카드 재노출)한다.

② 자주 찾는 질문 배치 — C안 확정(대화영역 안)

  • 자주 찾는 질문은 대화영역 안에 둔다(C안). 첫 진입 시 대화영역 중앙에 큰 카드로 노출한다(사용자 확정, 유지). [ISS-150] 입력창 위 가로 칩은 상시 노출 — is-chat-started 게이팅 제거로 첫 진입·새 대화 직후·대화 중·붐빔 응답 중 모든 상태에서 표시(세로 1줄 · 넘치면 가로 스크롤 · 접기 토글 없음). 붐빔 응답 시 자주 찾는 질문이 유일한 탈출로이기 때문. 칩/카드 클릭 시 질문이 입력창(#aihdInput)에 채워진다. 데이터는 기존 aiHelpdeskTags(AI_HELPDESK_TAGS)의 helpConsult/subsidy를 재사용.
  • ★[ISS-150 알림] 칩 상시 노출로, 첫 진입 화면에서는 웰컴 큰 카드와 입력창 위 칩이 동일한 자주 찾는 질문을 두 번 노출한다. 웰컴 큰 카드(C안, 사용자 확정)는 임의로 지우지 않고 그대로 두었다 — 이 중복 표시 조정 여부는 사용자가 화면을 보고 판단(미정).

③ 정원 초과(붐빔) 응답 표시 — 미정(개발 협의)

  • 배경(서버 제약) : 동시 접속 정원 40명, 유휴 30초 시 스레드 해제. 정원 초과 시 서버가 붐빔 안내를 응답 메시지로 반환하며, 화면은 그 응답 표시만 담당(감지 로직 없음). 붐빔 응답은 경고 톤 말풍선 + 재시도 + 대안 경로(자주 찾는 질문 · 질의응답 inquiry-qna.html · 콜센터 1661-0970)로 설계됐다.
  • [ISS-143 후속] 붐빔 응답 표시 복원 : 트리거가 배치안 비교 바에 얹혀 있던 게 실수였을 뿐 기능 자체는 운영 실동작이므로, 경고 톤 말풍선 · 다시 시도(직전 질문 재전송) · 대안 경로를 복원했다. 트리거는 배치안 바가 아니라 아래 시연 토글로 분리했다. 붐빔 응답의 실제 안내 문구·트리거 조건은 서버 연동 후 확정 필요(미정 · 개발 협의) — 화면에는 자리표시자만, 임의 문구를 창작하지 않았다.

④ 이번 범위 밖(별도 협의 필요)

  • 유휴 30초 스레드 해제로 인한 맥락 단절 : 이용자가 답변을 읽는 동안 30초가 지나 스레드가 끊기면, 이어지는 후속 질문에서 앞 대화 맥락이 이어지지 않을 수 있다. 세션 유지·재연결·맥락 복원 등 화면 처리 방식은 이번 설계 범위 밖 — 별도 협의 필요.

⑤ 그 밖의 규칙 — 메인 페이지와 동일

  • 이 문서는 전용 페이지에서 달라지는 점만 기술한다. 여기에 적지 않은 나머지 동작 규칙(문답 렌더링 · 마크다운 처리 · 참고 문서 표기 · 전송 동작 등)은 메인 페이지 AI 헬프데스크(index.html 의 <section id="AIhelpdesk">, 422행 부근)의 작동 규칙과 동일하다. 공통 렌더러 AiChatRender 와 assets/css/aiChat.css 를 그대로 사용한다. 중복 기술은 나중에 어긋나므로 메인 규칙을 여기에 옮겨 적지 않고 참조만 남긴다.
