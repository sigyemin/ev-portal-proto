버튼

기본 .button(높이 40px · 14px · radius 6px · 테두리 #061039) + 변형/크기 조합.

변형 (variant)

<button type="button" class="button">기본</button>
<button type="button" class="button button--primary">주요</button>
<button type="button" class="button button--primary-light">연한 주요</button>
<button type="button" class="button button--secondary">보조</button>
<button type="button" class="button button--primary button--outline">외곽선</button>
<button type="button" class="button" disabled>비활성</button>

크기 (size)

<button class="button button--primary button--lg">큰 버튼</button>
<button class="button button--primary button--sm">작은</button>
<button class="button button--primary button--rounded">둥근</button>

폼

상용 셀렉트박스는 <select>가 아니라 .selectbox + .select-container 커스텀 드롭다운이다.

셀렉트박스 (.selectbox)

<div class="selectbox" role="select">
  <button type="button" class="selectbox__button">
    <span class="selectbox__button-label">전체 사업자 (161)</span>
  </button>
  <div class="select-container" aria-haspopup="true">
    <ul class="select-container__list">
      <li class="select-container__item">
        <button type="button" class="select-container__button">옵션A</button>
      </li>
      <li class="select-container__item select-container__item--selected">
        <button type="button" class="select-container__button">선택된 옵션</button>
      </li>
    </ul>
  </div>
</div>

브레드크럼 (.breadcrumb)

상용은 각 단계가 드롭다운(.selectbox)이다 — 단순 텍스트가 아님.

<nav class="breadcrumb" aria-label="현재 위치">
  <ol class="breadcrumb__list">
    <li class="breadcrumb__item breadcrumb__item--home">
      <a href="/ui/main" class="breadcrumb__link" aria-label="홈으로 이동">
        <svg class="svg-icon">…</svg><span class="hidden">홈</span></a></li>
    <li class="breadcrumb__item breadcrumb__item--menu">
      <div class="selectbox" role="select">…</div></li>
  </ol>
</nav>
